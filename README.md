A simple Quran Reader built with Python and Tkinter.
This app fetches Quran verses using the AlQuran Cloud API and displays both Arabic (Uthmani script) and English translation (Sahih International).

Users enter a Surah number (1–114) and Ayah number to instantly load the verse inside a clean graphical interface.

🔹 Requirements
Python 3.8+
Internet connection
requests library

Install dependency:
pip install requests

🔹 Run the App
Clone the repository:
git clone https://github.com/your-username/repository-name.git


Open the project folder:
cd repository-name


Run the file:
python main.py
